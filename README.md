# 多功能电子钟 · AT89C51 + LCD1602

一个基于 8051（AT89C51）和 LCD1602 的多功能电子钟，包含时钟、日期、秒表、整点报时四大功能，全部代码集中在单个 `main.c` 中（约 780 行，编译后 3.1KB），适合单片机入门学习、课程设计复刻与二次修改。

源码为纯 C51，不依赖任何第三方库，只用到了 `reg52.h` 和 `intrins.h`。

---

## 功能特性

| 功能 | 说明 |
| --- | --- |
| 时钟 | 时:分:秒，24 小时制，Timer0 50ms 中断累计，长期走时无累积误差 |
| 日期 | 年-月-日（2000~2099），自动处理闰年与大小月，日期随零点自动进位 |
| 时间/日期设置 | 按键选择要调整的项（时/分/秒、年/月/日），支持长按连加连减 |
| 秒表 | 精度 0.1 秒，最长 99:59.9，支持启动 / 暂停 / 继续 / 停止 / 清零 |
| 整点报时 | 每逢整点"五短一长"循环鸣叫，按 K1 停止；响铃期间屏蔽其他按键 |
| 上电初值 | 默认用编译时刻（`__TIME__` / `__DATE__`）初始化，上电即显示当前真实时间 |

## 显示界面

LCD1602 为 16×2 字符屏，各界面如下（`_` 表示空格）：

```
  TIME 12:34:56             TIME SET: HOUR
  DATE 2026-11-11           12:34:56

  DATE SET: MONTH           STOPWATCH  RUN
  2026-11-11                03:25.7

  TIME 12:34:56
  ALARM! PRESS K1          <- 整点响铃时第二行提示
```

## 硬件与接线

| 器件 | 型号 / 参数 | 说明 |
| --- | --- | --- |
| 单片机 | AT89C51（或 AT89S52 等 8051 兼容芯片） | 12MHz 晶振，复位电路 + 上拉 |
| 显示屏 | LCD1602（LM016L） | 8 位并口，5×7 点阵 |
| 按键 | 4 个独立按键 | 低电平有效，内部/外部上拉 |
| 蜂鸣器 | 有源蜂鸣器 + PNP 三极管 | 低电平导通发声 |
| 晶振 | 12MHz | 若改用 11.0592MHz，需同步修改 `FOSC` |

| 信号 | 单片机引脚 |
| --- | --- |
| LCD 数据 D0~D7 | P0.0 ~ P0.7 |
| LCD RS | P2.0 |
| LCD RW | P2.1 |
| LCD E | P2.2 |
| 按键 K1 | P2.3 |
| 按键 K2 | P2.4 |
| 按键 K3 | P2.5 |
| 按键 K4 | P2.6 |
| 蜂鸣器 | P2.7 |

> P0 口作为数据口时，实际电路中需要 10kΩ 排阻上拉（Proteus 仿真中可省略）。

## 按键操作

| 当前界面 | K1 | K2 | K3 | K4 |
| --- | --- | --- | --- | --- |
| 时钟显示 | 进入秒表 | 进入调时间 | 进入调日期 | — |
| 调时间 | 保存并返回 | 切换 时/分/秒 | 加 | 减 |
| 调日期 | 保存并返回 | 切换 年/月/日 | 加 | 减 |
| 秒表 | 返回时钟 | 启动 / 暂停 / 继续 | 停止 | 清零 |
| 整点响铃中 | 停止鸣叫 | 屏蔽 | 屏蔽 | 屏蔽 |

在调时间 / 调日期界面，K3、K4 长按 500ms 后进入连加 / 连减，每 100ms 触发一次。

## 编译（Keil uVision5 + C51）

1. 用 Keil uVision5 打开 `CLOCK/CLOCK.uvproj`。
2. 目标 `Target 1` 已配置为 AT89C51、12MHz、`Create HEX File`。
3. `Project → Rebuild all target files`，生成的固件位于 `CLOCK/Objects/CLOCK.hex`。

编译结果（Keil C51 V9.60）：

```
Program Size: data=57.0 xdata=0 code=3177
0 Error(s), 0 Warning(s)
```

## 仿真（Proteus 8）

1. 打开 `CLOCK/CLOCK.pdsprj`。
2. 工程里 AT89C51 的 `Program File` 默认指向 `Objects\CLOCK.hex`（相对工程目录）。
   仓库不提交构建产物，如果没有该文件：
   - 用 Keil 重新编译一次，或
   - 把 `firmware/CLOCK.hex` 复制为 `CLOCK/Objects/CLOCK.hex`，或
   - 在 Proteus 中把 MCU 的 `Program File` 改为 `firmware/CLOCK.hex`。
3. 确认 MCU 属性中 `Clock Frequency` 为 `12MHz`，点击运行即可。

> 上电后蜂鸣器会短鸣约 1 秒，这是开机自检提示，属正常现象。

## 二次开发提示

- **改晶振**：修改 `main.c` 顶部的 `#define FOSC 12000000UL`，定时器与延时自动适配。
- **改初始时间**：把 `USE_BUILD_TIME` 改为 `0`，然后修改 `DEFAULT_*` 系列宏。
- **改报时节奏**：调整 `alarm_dur[]` 与 `alarm_lvl[]`（单位 50ms）。
- **换引脚**：LCD 与按键的引脚定义集中在文件前部的 `sbit` 与宏中。
- **只想要时钟**：删除秒表相关分支（`MODE_STOPWATCH`、`sw_*`）后仍小于 3KB。

## 已知限制

- 秒表上限 99:59.9，到顶自动停止。
- 年份范围 2000~2099，以两位十进制存储（`year = 26` 表示 2026 年）。
- 时钟精度取决于晶振精度，长时间运行建议改用 DS1302 等 RTC 芯片。
